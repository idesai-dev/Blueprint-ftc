# Pedro Pathing

If you want your robot to drive clean, accurate paths in autonomous, Pedro Pathing is the first thing we'd point you toward. It's a path-following library for FTC that handles the hard part of getting from one point to another along a curve, so you aren't writing motion code from scratch.

Why we like it:

- The driving looks natural. The robot flows through curves instead of doing stop-turn-go movements, which saves real time in a match.
- Getting decent results doesn't take forever. You aren't fighting the library to tune it.
- The community is active and the documentation is actually good, so when you get stuck there's somewhere to go.

We're not going to re-teach it here. The official docs do a better job than we could, and they stay current with the latest version. Start there:

[Pedro Pathing documentation →](https://pedropathing.com/)
